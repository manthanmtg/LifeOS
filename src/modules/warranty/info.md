# Warranty

Track warranties for appliances, devices, and other household items.

- Add a record with only an item name, then complete coverage details later.
- Add one or more coverage periods for manufacturer, component, seller, or extended plans.
- Upload bills, invoices, certificates, manuals, service receipts, photos, and other files directly to the item. Files are private and limited to 5 MB each.
- Images and PDFs can be previewed by supported clients; every file can be downloaded.
- Add service records to retain repair and maintenance history after coverage expires.
- Warranty expiry reminders use the notification channels configured in Settings. Coverage needs a start date and end date before a reminder can be scheduled.

Warranty records and files are private. Archiving an item retains its history and files while stopping future changes and reminders.
